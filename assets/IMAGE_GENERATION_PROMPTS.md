# ChatGPT image-generation prompts for ResumeLoop

These are **prompts only**; no artwork is generated or bundled in this starter. Each design asset must be created intentionally in ChatGPT image creation and then saved at the stated path. Never imply generated artwork is a real screenshot or a verified metric. Avoid company logos, copyrighted design copying and invented UI statistics.

## Global reusable art direction
Premium modern B2B SaaS illustration; single disciplined editorial visual language, stylised clean vector-like geometry, subtle spatial depth only when useful, generous breathing room, brand accent **#6C5CE7**, harmonious neutral palette, high legibility at small sizes, light-theme compatible, clear silhouette, NO text, numbers, logo, watermark, fake chart labels or UI screenshots, no photorealistic fake staff/customer. Export crisp PNG/WebP; for icons request transparent background, for empty states request transparent or pure light neutral according to implementation slot.

**Paste into ChatGPT image generation:**

> Create a 1600x900, landscape premium clean vector-style illustration for the ResumeLoop application. Central concept: **Abstract paper journey ribbon with a small pause and a clear re-entry point**. Palette anchored in #6C5CE7 with balanced neutral creams, soft slate, precise dark outlining if needed. One focal object, restrained ornament, generous safe margins, no text, no numbers, no brand marks, no human faces, no UI screenshot, no gradient-heavy 3D, no watermark. Crisp scalable composition; suitable for a calm enterprise analytics product. Keep the subject clear at 128 px. Save as `learner-resume-hero.png`.

**Review:** compare color, complexity and optical margins against the other assets; reject artifacts that contain illegible pseudo-letters or false charts.
