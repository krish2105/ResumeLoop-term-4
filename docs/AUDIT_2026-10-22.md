## Security and privacy boundary
**VERIFIED OBSERVATION:** Routes remain unauthenticated and CORS permits only the two localhost port-3000 origins (with broad methods/headers). CORS is not authorization. Bound servers are local only. SQLite and browser drafts are unencrypted and contain synthetic examples. JSON requests have a 150,000-character field limit after parsing, not an ingress byte/rate limit. No roles, tenant isolation, consent ledger, approved deletion process, backups/restore verification, request throttling or public hosting exists. Do not onboard real learner data before the pilot gates in `docs/SECURITY_AND_SAAS.md`.

React renders imported strings as text; SQL uses bound parameters. Raw synthetic CSV and normalized snapshots are retained in the receipt transaction. A hash is provenance, not proof of source authority. Exact-byte idempotency deliberately treats changed whitespace/line endings as a new source version; stable row IDs prevent duplicate records. Invalid batches are rejected rather than persisted in quarantine, minimizing retention of accidentally pasted personal information. Cross-tab edits to a shared browser draft are not coordinated.

Dependency scans report known advisories at scan time, not application security certification. Python tests emit a Starlette TestClient/httpx deprecation warning; tests still pass. Linux/Windows, other Python/Node versions, Safari/Firefox, assistive-technology sessions and production deployment remain unverified.
